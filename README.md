## 1) 按天执行计划（7天）

### D1｜9/25（周五）成都城市慢游
- 路线：人民公园 → 宽窄巷子 → 奎星楼街 → 九眼桥
- 建议时间：
  - 09:30 人民公园（鹤鸣茶社）
  - 12:00 午饭（奎星楼街川菜）
  - 14:00 宽窄巷子拍照逛街
  - 18:30 晚饭
  - 20:30 九眼桥夜景
- 住宿：成都（春熙路/太古里或宽窄巷子周边）

### D2｜9/26（周六）成都经典打卡
- 路线：熊猫基地（早场）→ 武侯祠/锦里 → 春熙路太古里
- 建议时间：
  - 07:30 出发去熊猫基地（尽量早进）
  - 11:30 午饭（武侯祠附近）
  - 13:00 武侯祠 + 锦里
  - 17:00 春熙路太古里
  - 20:00 成都火锅
- 住宿：成都（与前一晚同酒店，方便行李）

### D3｜9/27（周日）成都 → 康定 → 新都桥
- 里程/时长：约 430km，8-9 小时（含中途停靠）
- 路线：成都 → 雅安 → 泸定 → 康定 → 折多山 → 新都桥
- 建议时间：
  - 07:30 成都出发
  - 12:00 康定午饭
  - 14:00 加油（康定城区补满）
  - 16:30 折多山垭口短停
  - 18:30 抵达新都桥
- 住宿：新都桥（优先供氧/电热毯）

### D4｜9/28（周一）新都桥 → 塔公 → 墨石公园 → 丹巴
- 里程/时长：约 220km，5-6 小时
- 建议时间：
  - 08:30 出发
  - 10:00 塔公草原
  - 12:00 午饭（塔公/八美）
  - 13:30 墨石公园
  - 16:00 途中加油（八美/道孚方向视油量）
  - 18:30 抵达丹巴
- 住宿：丹巴县城（主路附近、停车方便）

### D5｜9/29（周二）丹巴 → 四姑娘山双桥沟 → 日隆镇
- 里程/时长：约 140km，4-5 小时
- 建议时间：
  - 08:30 出发
  - 11:30 到四姑娘山镇午饭
  - 13:00 双桥沟（门票+观光车）
  - 17:30 出景区
  - 18:00 入住日隆镇
- 住宿：日隆镇（尽量靠景区入口）

### D6｜9/30（周三）日隆 → 卧龙 → 映秀 → 都江堰
- 里程/时长：约 180km，4-5 小时
- 建议时间：
  - 09:00 出发
  - 12:00 映秀午饭
  - 14:00 补油（映秀/都江堰方向）
  - 16:00 抵达都江堰
  - 19:00 晚饭
- 住宿：都江堰（返蓉方便）

### D7｜10/1（周四）都江堰/青城山半日 → 成都
- 里程/时长：约 70km，1.5-2 小时
- 建议时间：
  - 08:30 酒店出发
  - 09:00-12:00 都江堰景区或青城山前山（二选一）
  - 13:00 午饭后返蓉
  - 15:30 前后回到成都

## 3) 酒店选定策略（按住宿点）

### 成都（2晚）
- 区域：春熙路/太古里、宽窄巷子附近
- 条件：地铁步行 10 分钟内、可停车、评分 4.6+、可免费取消
- 房型建议：**2间房**（1标间 + 1大床 或 2标间）

### 新都桥（1晚）
- 条件：供氧（加分项）、电热毯、热水稳定、停车方便
- 提醒：昼夜温差大，优先看“保暖”和“高反友好”评价

### 丹巴（1晚）
- 条件：靠县城主路、临街但安静、停车方便、次日出发快

### 日隆镇（1晚）
- 条件：距离双桥沟入口近、早餐时间早、可寄存行李

### 都江堰（1晚）
- 条件：临近高速回城方向、停车便利、周边餐饮密集

> 国庆中秋建议提前 2-4 周锁房，优先可退订房源，避免后期涨价被动。

## 4) 物资清单（自驾+高海拔）

### 证件与支付
- 身份证、驾驶证、行驶证、交强险/商业险信息
- ETC、现金少量、移动支付备用电量

### 车辆装备
- 胎压泵、搭电线、拖车绳、反光背心、三角警示牌
- 玻璃水、防滑链（视天气）、备胎状态检查

### 穿着
- 冲锋衣/抓绒、防风保暖层、速干衣、舒适徒步鞋
- 墨镜、防晒、帽子

### 药品与补给
- 高反常备药、肠胃药、感冒药、止痛药、创可贴
- 饮用水、功能饮料、能量棒、巧克力

### 数码
- 车充、充电宝、离线地图、行车记录仪、手机支架

## 5) 3人自驾执行规则（建议）

1. **驾驶轮换**：单人连续驾驶不超过 4 小时；至少 2 人可接替。
2. **出发原则**：每天尽量 8:00 前后出发，避免夜间山路。
3. **补油策略**：到县城/大站就补满，不赌下一个油站。
4. **高反策略**：首晚不剧烈运动、不饮酒、少洗过热澡，多喝水。
5. **天气兜底**：雨雪雾天优先安全，必要时砍景点不赶夜路。

## 6) 关键提醒

- 熊猫基地、四姑娘山双桥沟节假日建议提前预约。
- 国庆高峰路段可能拥堵，建议每日预留 1-2 小时机动时间。
- 若出现明显高反或极端天气，优先调整到低海拔并就近休整。

## 7) 天气与路况预案（执行版）

### 前一晚（22:00）
- 查看次日沿线天气：降雨/降雪/大风/能见度。
- 查看关键路段通行：封路、施工、塌方、拥堵预警。
- 确认次日主路线 A 与备选路线 B。

### 出发前（07:00）
- 二次确认实时路况和天气变化。
- 设定当日“最晚进山时间”和“最晚掉头时间”（建议 15:30）。
- 若预计严重拥堵或恶劣天气，主动减景点，不赶夜路。

### 路上执行规则
- 导航显示拥堵 > 60 分钟：优先切换 B 线或就近县城休整。
- 遇连续降雨/浓雾：降速、开灯、拉大车距，必要时停止前进。
- 临时封路不硬闯：不跟车冒险，撤回最近补给点等待窗口。

### 每天机动预留
- 机动时间：至少 1.5 小时/天。
- 机动预算：200-300 元/天（绕路油费、停车、临时补给）。

## 8) 通信与导航兜底（3人分工版）

### 角色分工
- A：主导航（车机/手机1）
- B：副导航（手机2，盯备选路与路况）
- C：通讯与记录（联系酒店、记录里程与节点）

### 出发前准备（建议 9/26 晚完成）
- 下载离线地图：成都、康定、新都桥、丹巴、四姑娘山、都江堰全区域。
- 收藏关键点：每日酒店、加油站、医院、交警队、县城中心。
- 建立走散会合规则：默认去“下一个县城服务区或加油站”。

### 无信号路段规则
- 不单车脱队，前后车保持可视距离。
- 岔路口必须停车确认，不凭感觉分路。
- 失联处理：原地等待 15 分钟 → 按预设会合点汇合，不反复折返。

### 紧急联系兜底
- 三人互存紧急联系人和证件信息照片。
- 预存酒店电话、保险救援电话、急救电话。
- 每晚 21:00 做次日通信检查（电量、充电宝、离线包、定位共享）。

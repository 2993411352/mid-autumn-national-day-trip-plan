行程设定：**9/25–10/4 共十天，从成都出发，串联四姑娘山、稻城亚丁、木格措后返回成都。**

## 1) 按天执行计划（10天）

- **D1–D2｜9/25–9/26** 成都城市慢游、熊猫基地、武侯祠/锦里与太古里。
- **D3｜9/27** 成都 → 映秀 → 卧龙 → 猫鼻梁 → 四姑娘山镇；约 175km，进山适应海拔。
- **D4｜9/28** 双桥沟完整一日；08:00 入园，观光车至红杉林后逐站下行。
- **D5｜9/29** 四姑娘山镇 → 丹巴 → 墨石公园 → 八美 → 新都桥；约 330km。
- **D6｜9/30** 新都桥 → 雅江 → 天路十八弯 → 卡子拉山 → 理塘 → 稻城 → 香格里拉镇；约 420km，纯转场日。
- **D7｜10/1** 稻城亚丁完整一日；身体状态优先，长短线现场决定，15:00 开始返程。
- **D8｜10/2** 香格里拉镇 → 稻城 → 海子山 → 理塘；约 230km，下午恢复。
- **D9｜10/3** 理塘 → 雅江 → 新都桥 → 折多山 → 康定；约 280km，拥堵时取消观景停靠。
- **D10｜10/4** 康定 → 木格措半日 → 泸定 → 雅安 → 成都；约 300km，最晚 13:00 离开木格措。

全程约 1,800km。D5、D6、D9 是重点风险驾驶日，原则是“不赶夜路；到达节点落后 90 分钟就取消后续观景点”。

## 3) 酒店选定策略（按住宿点）

### 成都（2晚）
- 区域：春熙路/太古里、宽窄巷子附近
- 条件：地铁步行 10 分钟内、可停车、评分 4.6+、可免费取消
- 房型建议：**2间房**（1标间 + 1大床 或 2标间）

### 新都桥（1晚）
- 条件：供氧（加分项）、电热毯、热水稳定、停车方便
- 提醒：昼夜温差大，优先看“保暖”和“高反友好”评价

### 丹巴（1晚）
- 条件：靠县城主路、临街但安静、停车方便、次日出发快

### 日隆镇（1晚）
- 条件：距离双桥沟入口近、早餐时间早、可寄存行李

### 都江堰（1晚）
- 条件：临近高速回城方向、停车便利、周边餐饮密集

> 国庆中秋建议提前 2-4 周锁房，优先可退订房源，避免后期涨价被动。

## 4) 物资清单（自驾+高海拔）

### 证件与支付
- 身份证、驾驶证、行驶证、交强险/商业险信息
- ETC、现金少量、移动支付备用电量

### 车辆装备
- 胎压泵、搭电线、拖车绳、反光背心、三角警示牌
- 玻璃水、防滑链（视天气）、备胎状态检查

### 穿着
- 冲锋衣/抓绒、防风保暖层、速干衣、舒适徒步鞋
- 墨镜、防晒、帽子

### 药品与补给
- 高反常备药、肠胃药、感冒药、止痛药、创可贴
- 饮用水、功能饮料、能量棒、巧克力

### 数码
- 车充、充电宝、离线地图、行车记录仪、手机支架

## 5) 3人自驾执行规则（建议）

1. **驾驶轮换**：单人连续驾驶不超过 4 小时；至少 2 人可接替。
2. **出发原则**：每天尽量 8:00 前后出发，避免夜间山路。
3. **补油策略**：到县城/大站就补满，不赌下一个油站。
4. **高反策略**：首晚不剧烈运动、不饮酒、少洗过热澡，多喝水。
5. **天气兜底**：雨雪雾天优先安全，必要时砍景点不赶夜路。

## 6) 关键提醒

- 熊猫基地、四姑娘山双桥沟节假日建议提前预约。
- 国庆高峰路段可能拥堵，建议每日预留 1-2 小时机动时间。
- 若出现明显高反或极端天气，优先调整到低海拔并就近休整。

## 7) 天气与路况预案（执行版）

### 前一晚（22:00）
- 查看次日沿线天气：降雨/降雪/大风/能见度。
- 查看关键路段通行：封路、施工、塌方、拥堵预警。
- 确认次日主路线 A 与备选路线 B。

### 出发前（07:00）
- 二次确认实时路况和天气变化。
- 设定当日“最晚进山时间”和“最晚掉头时间”（建议 15:30）。
- 若预计严重拥堵或恶劣天气，主动减景点，不赶夜路。

### 路上执行规则
- 导航显示拥堵 > 60 分钟：优先切换 B 线或就近县城休整。
- 遇连续降雨/浓雾：降速、开灯、拉大车距，必要时停止前进。
- 临时封路不硬闯：不跟车冒险，撤回最近补给点等待窗口。

### 每天机动预留
- 机动时间：至少 1.5 小时/天。
- 机动预算：200-300 元/天（绕路油费、停车、临时补给）。

---

## 8) 通信与导航兜底（3人分工版）

### 角色分工
- A：主导航（车机/手机1）
- B：副导航（手机2，盯备选路与路况）
- C：通讯与记录（联系酒店、记录里程与节点）

### 出发前准备（建议 9/26 晚完成）
- 下载离线地图：成都、康定、新都桥、丹巴、四姑娘山、都江堰全区域。
- 收藏关键点：每日酒店、加油站、医院、交警队、县城中心。
- 建立走散会合规则：默认去“下一个县城服务区或加油站”。

### 无信号路段规则
- 不单车脱队，前后车保持可视距离。
- 岔路口必须停车确认，不凭感觉分路。
- 失联处理：原地等待 15 分钟 → 按预设会合点汇合，不反复折返。

### 紧急联系兜底
- 三人互存紧急联系人和证件信息照片。
- 预存酒店电话、保险救援电话、急救电话。
- 每晚 21:00 做次日通信检查（电量、充电宝、离线包、定位共享）。
